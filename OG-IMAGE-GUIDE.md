# OG Image Creation Guide

## Required OG Image

Create an image at this exact location:
**Location**: `/public/og-image.png`

### Image Specifications:
- **Size**: 1200 x 630 pixels
- **Format**: PNG or JPG
- **Max file size**: Under 1MB

### Content to Include:
1. **Your Name**: Muhammad Hasan Baig (Large, bold)
2. **Title**: Next.js & React Developer
3. **Location**: Karachi, Pakistan
4. **Key Skills**: Next.js • React • TypeScript • Tailwind CSS
5. **Background**: Dark theme matching your portfolio
6. **Optional**: Your logo or professional photo

### Quick Creation Options:

#### Option 1: Use Canva (Free)
1. Go to canva.com
2. Create custom size: 1200 x 630
3. Use dark background
4. Add your text and logo
5. Download as PNG

#### Option 2: Use Figma (Free)
1. Create frame: 1200 x 630
2. Design with your branding
3. Export as PNG

#### Option 3: Use Online Tools
- https://www.opengraph.xyz/
- https://ogimage.xyz/
- https://og-playground.vercel.app/
